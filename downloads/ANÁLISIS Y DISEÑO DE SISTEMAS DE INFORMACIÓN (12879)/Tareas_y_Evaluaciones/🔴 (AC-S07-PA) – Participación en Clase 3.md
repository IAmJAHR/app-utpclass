## Indicaciones

1. Indicaciones generales: 
Esta actividad se realiza de manera individual.
Eres el diseñador de un sistema de gestión de horarios y clases para un gimnasio. El sistema debe abarcar funcionalidades de registro, programación y acceso, aplicables también a otros tipos de negocios.
Tu tarea consiste en modelar visualmente las interacciones entre los usuarios (actores) y el sistema, identificando los actores, los casos de uso y delimitando el sistema.
El modelo debe reflejar funcionalidades clave como: gestión de clases, visualización de horarios, reservas, gestión de membresías y envío de notificaciones.
Deberás presentar un diagrama de casos de uso claro y justificado, que muestre las funcionalidades desde la perspectiva del usuario, utilizando las técnicas de la semana.
Usa Visual Paradigm para crear el Diagrama de caso de uso.
 
2. Indicaciones específicas: 
a. Nombre del entregable: Entregable en formato PDF con la siguiente denominación: ParticipaciónenClase3_Nombredelestudiante.
b. Vía de entrega: Plataforma virtual de aprendizaje.
c. Estructura del entregable:
I. Identificación de actores: Señala los distintos usuarios que interactúan con el sistema (ej. administrador, miembro del gimnasio, instructor).
II. Definición de casos de uso: Especifica las principales funcionalidades que el sistema debe contemplar (gestión de clases, visualización de horarios, reservas, gestión de membresías y notificaciones).
III. Delimitación del sistema: Indica de forma clara qué procesos pertenecen al sistema y cuáles quedan fuera de su alcance.
IV. Elaboración del diagrama: Presenta un diagrama de casos de uso creado en Visual Paradigm, que muestre las interacciones entre los actores y el sistema, con notación correcta y justificación breve de las decisiones tomadas.
V. Usa Visual Paradigm para crear el diagrama de caso de uso.
 
d. Formato de entrega: Archivo PDF con los diagramas solicitados y una breve explicación de cada uno (máx. 150 palabras). Fuente Arial 11, interlineado simple, uso de normas APA.
